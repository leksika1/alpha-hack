## Внешние сервисы и источники

| Сервис | Использование | Условия |
|---|---|---|
| Новостные RSS/открытые API | сбор новостей (перечень и статус — `docs/SOURCES.md`) | только публичные фиды; robots.txt, User-Agent, rate limit |
| LLM-провайдер организаторов (OpenAI-совместимый API) | генерация через LLM Gateway | общий ключ, лимит ~500 ₽/день |
