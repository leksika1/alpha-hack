# Развитие

Направления, которые не входят в текущую версию. Ссылки — на решения, где они обоснованы.

## Данные и матчинг
- Тип связи по платежам (поставщик или покупатель) с учётом ОКВЭД обеих сторон.
- Режим «вся клиентская база» (`MATCH_SCOPE=all`): очистка устаревших кандидатов по сроку события; запись
  кандидатов через `COPY` и скоринг батчей в пуле процессов — запас к цели 5 с на событие (ADR-029).
- Срочность «событие у контрагента» по упоминанию компаний — когда в данных появятся наименования.

## Новости
- Профильные отраслевые издания (металлургия, нефтегаз) — по договорённости, их ленты закрыты от ботов.
- Текст новости со страницы статьи для источников вида `html` (сейчас — только заголовок).
- Склейка дублей и поиск новостей по эмбеддингам, в том числе между языками (ADR-021, ADR-039).
- Перевод или пересказ англоязычных новостей на русский перед агентом — вместе с ML-сервисом.
- Другие рыночные индикаторы для агента (нефть, металлы) — при наличии официального бесплатного источника.

## Аналитика банка
- Извлечение таблиц и графиков из PDF через Qwen3-VL (за флагом, ADR-005).
- Дата и название для обложек-картинок без текстового слоя.
- Реранкер поверх гибридного поиска (ADR-024).

## Эксплуатация
- Копирование резервных копий во внешнее хранилище по расписанию.
- Уникальные алиасы инфраструктуры проекта в общей сети Dokploy (ADR-032).
