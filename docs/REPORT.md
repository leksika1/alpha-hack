## Границы ответственности

- **ML-команда** — промпты, логика агента, тексты инсайтов и ответов, выбор моделей (LLM, эмбеддинги),
  правила релевантности. Бэкенд даёт контракты, инструменты, Gateway, проверку результата и `ml-stub` как
  детерминированную замену. Подключение — `INSIGHT_GENERATOR=remote`.
- **Фронтенд** — интерфейс по `docs/openapi.json` и `docs/INTEGRATION_FRONTEND.md`.

## Ограничения

`docs/SPEC.md` §16. Главные:
- тексты в прототипе — шаблоны `ml-stub`, пока не подключён агент ML;
- модель эмбеддингов не выбрана (по умолчанию `fake`, поиск держится на полнотекстовой части);
- тарифы LLM неизвестны — бюджет считается с запасом;
- графики и таблицы в PDF распознаются частично;
- матчинг события по всей базе — 4,1 с при цели 5 с (запас небольшой).

## Решения за человеком

1. Слияние `dev → main` и тег `v1.0.0` — требование сдачи (кейс, стр. 8).
2. Доступ к репозиторию для `alfa-hack-2026` (кейс, стр. 8): настройки репозитория на GitHub → Collaborators.
3. `LLM_BASE_URL` / `LLM_API_KEY` и тарифы моделей — от организаторов.
4. Модель эмбеддингов — решение ML-команды.
