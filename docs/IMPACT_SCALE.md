# Шкала влияния события на компанию (scale_version = 1)

Поле контракта `impact`: `level` ∈ {low, medium, high, critical}, `score` 0–100, опционально `quantitative`, `scale_version`.
Шкала оценивает **влияние на конкретную компанию**, а не важность новости вообще.

## Как считается score (baseline)

```
score = 100 · exposure · magnitude · proximity        (округление до целого, клип 0..100)
exposure, proximity — по сильнейшему компоненту скоринга (app/domain/scoring.py)
```

| Множитель | Смысл | Как оценивается baseline-правилами |
|---|---|---|
| `exposure` (0–1) | Насколько компания подвержена фактору события | признаки `company_context`: доля платежей с контрагентами затронутой отрасли, наличие кредита/лизинга при событии по ставке, страны ВЭД ∩ страны события, отрасль компании ∩ отрасли события, данные пользователя |
| `magnitude` (0–1) | Сила самого события | по типу: ставка — сохранение 0,6 / снижение 0,7 / повышение 0,9; санкции 0,8; курс, пошлины и налоги, компания 0,6; торговля и логистика 0,55; сырьё 0,5; отрасль 0,4; макростатистика, рынок труда 0,35; прочее 0,3. Для сырья, курса и пошлин с числом в % — не меньше 0,4 + %/25 (до 0,9); срочное событие — не меньше 0,8. Реализация — `app/domain/impact.py` |
| `proximity` (0.3–1) | Прямое или косвенное влияние (по сильнейшей причине) | 1.0 — сама компания/группа; 0.9 — собственный продукт/контракт компании затронут напрямую (кредит/лизинг при решении по ставке, страна ВЭД компании, данные пользователя); 0.8 — прямой контрагент (топ-10 или отрасль значимых контрагентов); 0.7 — сырьё компании; 0.6 — отрасль компании, потребительский спрос; 0.4 — регион, регуляторный фон; 0.3 — общий фон |

ML-генератор может переопределить score, но обязан оставить `level` согласованным с диапазонами ниже (проверяет валидатор).

## Уровни

| level | score | Определение | Типичные примеры | Доставка |
|---|---|---|---|---|
| `low` | 0–24 | Фоновое событие: влияние косвенное, на ключевые показатели компании в горизонте квартала заметно не повлияет | общая статистика по отрасли без изменения трендов; событие у контрагента с долей < 1% оборота | только лента |
| `medium` | 25–49 | Влияет на отдельные показатели (затраты, сроки, условия), требует внимания профильного руководителя, но не решений «сегодня» | изменение пошлин по стране ВЭД со значимой, но не основной долей; прогноз банка по ставке для компании с кредитом | лента + дайджест |
| `high` | 50–74 | Существенное влияние на финансовый результат, ликвидность или операционную деятельность; есть смысл в действиях в горизонте недель | решение ЦБ по ставке для компании с кредитами и лизингом; санкции против страны — основного направления ВЭД; проблемы у контрагента с долей > 10% | лента (вверху) + дайджест; при `urgent` — уведомление |
| `critical` | 75–100 | Угроза непрерывности бизнеса или крупная немедленная возможность; требует решения в горизонте дней | блокировка ключевого торгового направления; банкротство/санкции против крупнейшего контрагента; резкий скачок курса при высокой валютной нагрузке | немедленное SSE-уведомление + закреп в ленте |

## Количественная оценка (`impact.quantitative`)

Для `high` и `critical` желательна, для остальных — по возможности. Формат:
`{metric, value, unit, basis, period}`; `basis` обязательно объясняет расчёт и ссылается на признаки (`feature_refs`).

Метрики, вычислимые из имеющихся данных (без выдумывания):

| Метрика | Расчёт | Источник |
|---|---|---|
| `counterparty_share_affected` | доля оборота (входящего/исходящего) с контрагентами из затронутой отрасли/группы, % | `payments_agg` + `company_context` |
| `counterparty_hhi` | концентрация контрагентов (HHI 0–10 000) — устойчивость к выпадению контрагента | `company_context` |
| `rate_change_pp` | изменение ключевой ставки, п.п. (из события или аналитики банка) | новость / `analytics_chunks` |
| `interest_cost_delta_per_100m` | Δ процентных расходов на каждые 100 млн ₽ плавающего долга, ₽/год (= Δставки · 1 млн) | событие; сумма долга неизвестна → только «на 100 млн» |
| `fx_countries_affected` | число стран ВЭД компании, затронутых событием, и их перечень | `company_fts_countries` |
| `revenue_scale_rub` | выручка компании/группы как масштаб для оценки (не прогноз!) | `companies`, `company_groups` |

Запрещено: оценивать в рублях то, для чего нет исходных данных (например, сумму кредита) — вместо этого нормировка
«на 100 млн» или доля. Неизвестное — явно в `basis` («сумма долга неизвестна»).

## Срочность (`urgent`) ≠ уровень влияния

`urgent=true` — событие требует быстрого пути доставки (решение ЦБ, санкции, события по прямым контрагентам, ЧС).
Инсайт отправляется уведомлением, если `urgent=true` **и** `level ∈ {high, critical}`.
