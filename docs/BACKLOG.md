# BACKLOG — идеи и долги вне текущих задач

Формат: `- [область] описание — откуда взялось (фаза/файл)`.

- [data] Справочник нормализации названий регионов/городов (вариации «Мск "Юг"», «г. Москва») — фаза 0, профилирование.
- [data] Гипотезы о типе связи по платежам (поставщик/покупатель) с учётом ОКВЭД обеих сторон — фаза 1 (минимум), расширение позже.
- [analytics] VLM-извлечение таблиц/графиков из PDF через Qwen3-VL (за флагом) — ADR-005; сейчас цифры графиков отфильтрованы как шум, часть остаётся внутри абзацев (docs/DATA.md).
- [analytics] Обложки-картинки (Gold digest): название берётся из OCR обложки или имени файла; дата «август 2026» без дня не распознаётся (`NULL`).
- [news] Near-duplicate через MinHash вместо эмбеддингов для очень больших потоков — фаза 3.
- [ops] Бэкапы Postgres/MinIO по расписанию (pg_dump + mc mirror) — RUNBOOK.
- [ops] Деплой на бесплатный внешний сервер (рекомендация кейса, стр. 8).
- [matching] `MATCH_SCOPE=all` пишет кандидатов для всей базы (~29 тыс. строк на событие о ставке): очистка старых кандидатов по TTL событий — ADR-029.
- [ml] Скорер: буст «регулирование» от любого ненулевого компонента даёт ~0,4 при 0,35 % платежей в отрасли — решение за ML (ADR-029).
- [matching] `MATCH_SCOPE=all`: запись кандидатов через COPY во временную таблицу + один upsert и скоринг батчей в пуле процессов — дополнительный запас к NFR-3 (сейчас 4,1 с на событии о ставке) — ADR-029.
- [news] Отраслевые RSS для металлургии, логистики, нефтегаза (кандидаты из docs/SOURCES.md недоступны) — фаза 3.
- [news] ТАСС: включить после явного разрешения (robots.txt отвечает 403) — docs/SOURCES.md.
- [news] Коннекторы `json_api` и `html` (сейчас не нужны: все рабочие источники — RSS) — app/integrations/news/connectors.py.
- [news] Эмбеддинги новостей: гибридный `search_news`, почти-дубли и склейка по векторам поверх ADR-021 (инфраструктура `EmbeddingProvider` готова в фазе 4).
- [news] Метрики сбора в Prometheus из воркера (сейчас — `core.news_raw`/`core.sources`; витрина — `/admin/sources/health`, фаза 6).
- [market] RSS курсов ЦБ (`cbr.ru/rss/RssCurrency`) — источник для `get_market_data` (ключевая ставка, курсы).
- [news] Срочность «событие у контрагента» — по упоминанию компаний (в обезличенных данных нет наименований).
- [analytics] Реранкер (cross-encoder) поверх RRF — за интерфейсом, по решению ML — ADR-024.
- [ops] Dokploy: `api` и `worker` в общей `dokploy-network`, где имена `postgres`/`redis`/`minio` могут оказаться у
  чужого проекта; обращаться к своей инфраструктуре по уникальным алиасам проекта — ADR-032.
