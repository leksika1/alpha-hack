# BACKLOG — идеи и долги вне текущих задач

Формат: `- [область] описание — откуда взялось (фаза/файл)`.

- [data] Справочник нормализации названий регионов/городов (вариации «Мск "Юг"», «г. Москва») — фаза 0, профилирование.
- [data] Гипотезы о типе связи по платежам (поставщик/покупатель) с учётом ОКВЭД обеих сторон — фаза 1 (минимум), расширение позже.
- [analytics] VLM-извлечение таблиц/графиков из PDF через Qwen3-VL (за флагом) — ADR-005.
- [news] Near-duplicate через MinHash вместо эмбеддингов для очень больших потоков — фаза 3.
- [ops] Бэкапы Postgres/MinIO по расписанию (pg_dump + mc mirror) — RUNBOOK.
- [ops] Деплой на бесплатный внешний сервер (рекомендация кейса, стр. 8).
