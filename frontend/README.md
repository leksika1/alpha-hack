# frontend — раздел «Аналитика» в имитации интернет-банка «Альфа-Бизнес»

Веб-интерфейс сервиса персонализированных инсайтов: главная «Альфа-Бизнеса» с постоянной точкой входа, лента
инсайтов, карточка инсайта с шестью блоками кейса, вопросы к аналитике, профиль компании, дайджест, заявки и
панель метрик для администратора. Путь пользователя построен по CJM финансового директора (8 этапов).

## Запуск

Вместе со всем стендом (из корня репозитория):

```bash
docker compose up -d --build
```

Интерфейс — http://localhost:3000 (порт — `FRONTEND_PORT`), `/api` проксируется на сервис `api`.

Для разработки (нужен Node 20+ и запущенный бэкенд на `http://localhost:8000`):

```bash
cd frontend
npm ci
npm run dev        # http://localhost:5173, /api → API_PROXY_TARGET (по умолчанию http://localhost:8000)
```

| Команда | Что делает |
|---|---|
| `npm run dev` | dev-сервер Vite с прокси на бэкенд |
| `npm run build` | проверка типов и сборка в `dist/` |
| `npm run typecheck` | только проверка типов |
| `npm run gen:api` | перегенерировать типы `src/api/schema.d.ts` из `../docs/openapi.json` |

## Демо-учётки

| Логин | Пароль | Что показать |
|---|---|---|
| `demo` | `demo12345` | 3 компании разных отраслей: смена компании меняет ленту |
| `demo2` | `demo12345` | агрохолдинг и девелопер |
| `admin` | `admin12345` | метрики CJM, бюджет LLM, источники, ручная новость через конвейер |

На странице входа учётки выбираются одним кликом.

## Сценарий для жюри (CJM)

| № | Этап | Где в интерфейсе |
|---|---|---|
| 01 | Заметить сервис | Главная → блок «Альфа-Аналитика · Важное для вашего бизнеса» (2–3 главных инсайта, счётчики, «почему это для вас»), пункт «Аналитика» в меню с числом непрочитанных |
| 02 | Подтвердить контекст | Шапка: переключатель «Мои компании»; раздел «Аналитика» → «Анализ подготовлен для…», выбор роли; вкладка «Профиль компании» — признаки с источником, полнота, анкета, связи (гипотезы помечены) |
| 03 | Выбрать важное | «Лента инсайтов»: фильтры (срочные, риски, возможности, сохранённые, скрытые), период, «почему выше в ленте» |
| 04 | Понять последствия | Карточка инсайта: что произошло → почему важно вам (признаки компании) → риски, возможности, сценарии, шкала влияния → что сделать → позиция банка |
| 05 | Проверить основания | «На чём основан вывод»: метки «Факт», «Аналитика Альфа-Банка», «Вывод AI», «Гипотеза», источники (новость в окне или PDF на нужной странице), разбор релевантности, трасса агента |
| 06 | Уточнить сценарий | «Уточнить сценарий» в инсайте и вкладка «Вопрос аналитику»: ответ потоком (SSE) с источниками и метками |
| 07 | Выбрать действие | «Связаться с менеджером», «Заказать звонок», «Оставить заявку» → номер в мок-CRM; «Наблюдать»; вкладка «Мои заявки» |
| 08 | Оценить и вернуться | «Инсайт был полезен?» → что сервис сделал с отзывом; скрытие и возврат; уведомления (колокольчик и всплывающие по SSE); «Дайджест» |

Проверка «свежие новости обрабатываются»: войти как `admin` → «Ручная новость через общий конвейер», затем
войти как `demo` — срочное событие придёт уведомлением и появится в ленте.

## Устройство

- React 18 + TypeScript + Vite, маршрутизация — `react-router-dom`, данные — `@tanstack/react-query`.
- Компоненты и токены дизайн-системы Альфа-Банка — `@alfalab/core-components`, иконки — `@alfalab/icons-glyph`
  ([Core DS](https://core-ds.github.io/core-components/master/)). Точное соответствие дизайн-системе не требуется
  кейсом; цель — чтобы раздел выглядел частью интернет-банка.
- `src/api` — клиент API (JWT, обновление токена, ошибки problem+json с `trace_id`), SSE через `fetch`
  (EventSource не умеет заголовок `Authorization`), хуки запросов.
- `src/layout` — оболочка «Альфа-Бизнеса» (меню, шапка, переключатель компаний, уведомления).
- `src/pages` — экраны; `src/components/insight` — блоки карточки инсайта.
- Синтетические демо-материалы показываются как есть («Демо-материал (синтетика)»), не подменяются на аналитику банка.
- Дисклеймеры инсайта выводятся всегда.
