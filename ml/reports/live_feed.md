поэтому часть ложных тегов стенда здесь не воспроизводится; оценка консервативна.

Цена правок — часть фоновых (gold=1) событий уходит из ленты (комментарии о ставке «по ходу», отраслевые новости
без изменения условий). Остаток шума — в основном спорные пары: топливный рынок для перевозчика, ставочные
комментарии для компании с депозитами, ипотека для металлотрейдера с покупателями-стройкой.

Классы ложных срабатываний, которые закрыты (тесты `test_live_feed_false_positives_are_screened`):
«FedEx»/иностранные ЦБ как ключевая ставка; «медики» → медь, «в прокат выходят» → стальной прокат, «Чугунный мост»;
санкционные заголовки без российской торговли; упоминание страны ВЭД без торговли; новости без экономического
содержания (война, культура, происшествия); инциденты отдельных фирм как изменение условий отрасли контрагентов.
