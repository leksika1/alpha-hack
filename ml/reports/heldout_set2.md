## Итог и что изменилось после прогона

**Слепой результат (таблица выше — честная цифра):** доля мусора у ML 20% против 56% у бэкенда, но **recall важных
0,06 против 1,0** — ML пропустил «Банк России повысил прогноз по средней ставке» у всех 8 заёмщиков и комментарии
о ставке («Шохин: ЦБ мог бы снизить ставку»). Причина — правило ADR-ML-010, добавленное по живой ленте: «ставка
только в тексте, не в заголовке → вес ×0,25». Заголовок без слов «ключевая ставка» считался обзором рынка. Это
подгонка под предыдущий набор, и слепой набор её поймал.

**Исправление (после прогона, набор №2 после него уже не слепой):** заголовок считается «про ставку», если в нём
есть само слово «ставка/ДКП/ДКУ»; обзоры рынка и дайджесты без него по-прежнему ×0,25.

|---|---|---|
| №2 (этот): recall важных / мусор / nDCG@5 / P@3 | 0,06 / 20% / 0,28 / 0,33 | 1,00 / 12% / 0,60 / 0,83 |
| Бэкенд без ML на №2 | 1,00 / 56% / 0,60 / 0,53 | — |
| Живая лента: мусор / recall важных | 41% / 1,0 | 41% / 1,0 |
| Демо-лента CFO: nDCG@5 / мусор | 0,946 / 20% | 0,946 / 20% |
| Отложенный №1 CFO: nDCG@5 / мусор | 0,826 / 2,5% | 0,826 / 2,5% |

Вывод: на новых данных правила хрупкие — одна правка под один набор обнулила полноту на важном классе другого.
Нужен постоянный слепой набор на каждый релиз и более устойчивая модель релевантности (`NEXT_STEPS.md`).
